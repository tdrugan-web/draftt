# EvidenceTag

The [E], [A], and [S] tags that mark every claim about users, markets, or numbers as evidence, assumption, or synthetic, as the skill standard requires.

- Place the tag right after the claim it qualifies, inline, never at the start of a paragraph.
- **[E] evidence** (`evidence`): give a `source` ("Interview 3", "Q3 support tickets"). An [E] without a source is an [A].
- **[A] assumption** (`assumption`): every [A] also appears in the artifact's assumptions list.
- **[S] synthetic** (`synthetic`): came from synthetic-user or roleplay. Never upgrade it to [E] by editing.
- Use `spelled` for the first tag of each kind in a document, then the short form. The three colors are close in lightness, so the letter is always shown and screen readers hear the word.
- Never restyle a tag as a badge, pill, or colored chip. It's a typographic mark, in `mono`, so it reads like an editor's annotation.
