# Logos

- `draftt-mark.svg`: the tt mark. Two t's share one crossbar, the way a typesetter's tt ligature does. Single ink, set with CSS `color`. Minimum size 16px. Clear space on every side equal to the crossbar's height.
- `draftt-mark-color.svg`: the two-ink mark. The second t, the revision, is `action`. Use on `paper` or `raised` only.
- `draftt-wordmark.svg`: "draftt" set in Newsreader 500, always lowercase. This is a live-text placeholder until the wordmark is drawn as outlines. Don't ship it in exports or favicons yet.

Never stretch, rotate, outline, or recolor the mark beyond `ink`, `action`, or `paper` (on a dark ground).
